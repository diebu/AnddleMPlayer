# AnddleMPlayer 回归检查

每次提交前运行：

```bash
./Scripts/check.sh
```

## 自动化覆盖

- Debug、Release 编译。
- 测试 Bundle 编译。
- 音频打断后暂停，第一次点击恢复。
- 打断结束后不自动播放。
- 断点续播边界。
- 切换文件后保留上一文件的最终播放进度。
- 重启 App 或刷新目录后，不能因全库扫描误删其他文件的播放进度。
- 顺序切到下一首时从头播放；从列表点选仍可断点续播。
- 定时停止状态。
- 大量导入、删除时显示持续处理动画，删除期间界面不卡死。
- 文件名换行保护。
- 音频导入过滤与目录结构。
- 循环模式轮转。

## 真机必测

这些行为依赖真实系统音频会话，模拟器或单元测试不能完全替代：

- 音乐播放中打开另一个发声 App，再返回本 App。
- 电话、微信语音、Siri 打断。
- 锁屏进度、播放/暂停、上一首/下一首。
- 蓝牙耳机、AirPods 和有线耳机断开/重连。
- 后台播放后从控制中心恢复。
- 在「文件」App 删除当前歌曲后返回本 App。
- CarPlay（如有测试设备）。
- 不同屏幕尺寸和 Dynamic Type。
