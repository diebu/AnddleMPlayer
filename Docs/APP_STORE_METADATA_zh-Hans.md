## 描述

```text
AnddleMPlayer 是一款专注本地文件的极简音乐播放器。无需登录，不上传音乐，把已有的音频文件放进 App 就可以开始聆听。

以文件夹为中心的曲库

• 按真实目录浏览音乐，不聚合、不隐藏文件夹层级
• 从“文件”App 或其他 App 多选导入文件与文件夹
• 可新建、重命名、移动和删除文件或文件夹
• 当前文件夹中的音频就是当前播放列表，子文件夹不会混入
• “我的 iPhone”下始终显示本 App，方便通过“文件”或 Finder 管理音乐

为长时间聆听而设计

• 支持 MP3、M4A、M4B、AAC、FLAC、WAV、AIFF、CAF
• 0.5×–2.0× 倍速播放，每次调整 0.1×
• 按时间或曲目数设置定时停止
• 自动保存每个文件的播放进度，再次打开即可断点续播
• 支持顺序播放、列表循环和单曲循环
• 支持后台播放、锁屏与控制中心控制、耳机线控

清晰、克制又顺手的播放体验

• 黑、白、红经典配色，也可切换为琥珀暖色配色
• 旋转黑胶唱片、随进度移动的唱针和清晰的文件夹标签
• 左右滑动跳转，双指点击快进，上滑切换 1.5× 播放
• 再次启动时恢复上次曲目、队列和播放位置

你的音乐文件保存在 App 自己的 Document 文件夹中，可随时通过“文件”App 或 Finder 管理。AnddleMPlayer 不提供在线曲库，也不会自动收集设备中的音乐。

适合：
• 自己整理的音乐收藏
• 有声书、长篇播客和课程音频
• 本地录音与练习素材

安安静静，好好听歌。
```

## 技术支持网址

提交前必须换成真实、无需登录即可访问的 HTTPS 页面，建议包含：

- App 名称与当前版本
- 支持邮箱
- 常见问题：如何导入音乐、支持哪些格式、如何删除文件、如何关闭定时停止
- 隐私政策入口

推荐格式：

```text
https://你的域名/anddlemplayer/support
```

不要填写尚未上线的占位地址，否则审核时可能无法访问。
