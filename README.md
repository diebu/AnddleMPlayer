# AnddleMPlayer

iOS 本地音乐播放器。App 的 Documents 目录本身就是音乐库，可以直接在里面增删改查文件；
界面只有黑、白、红三个颜色，封面保持原色，播放页背景由封面派生。纯 SwiftUI + AVFoundation，无第三方依赖。

## 怎么跑起来

1. 双击 `AnddleMPlayer.xcodeproj` 用 Xcode 打开。
2. target → Signing & Capabilities → 勾选 *Automatically manage signing*，Team 选你自己的 Apple ID。
3. 连上 iPhone，按 ⌘R。

要求 Xcode 16 以上 / iOS 17.0 以上。

## 音乐怎么进去

两种方式：

- **分享进来**：在「文件」里长按歌曲或文件夹 → 共享 → AnddleMPlayer（其他 App 里的分享菜单同样会列出本 App）。收到的内容会落到音乐库根目录，可以多个一起选。文件夹会连着子目录一起进来。
- **App 内导入**：点右上角 ＋ → 「导入文件或文件夹」。第一次会打开系统文件选择器，让用户授权一个目录作为导入起点；之后会记住这个安全作用域书签，直接进入 App 内的文件浏览器。

  浏览器普通状态下点文件夹进入下一级，点文件会立即选中该文件并出现「取消 / 导入」；点右上角「选择」则让每一行出现勾选圈。多选状态下，文件夹左侧圆圈负责选中文件夹，点行的其余部分仍然可以进入文件夹。选中的内容会拷进**当前这一层**，右上角标题菜单可以更换导入位置。

  **选中一个文件夹时，会连同文件夹本身一起导入**，进入它内部选择文件时，才会直接得到那些文件。分享进来的文件夹同样保留文件夹结构。
- **从网盘导入**：点右上角 ＋ → 「从网盘导入…」，直接打开系统文件选择器。iCloud Drive、百度网盘等已接入 iOS「文件」的网盘会出现在位置列表中，可以同时多选文件和文件夹，再复制到当前目录。读取网盘占位文件时使用 `NSFileCoordinator`，由系统先完成下载与协调。
- **拖进去**：`AnddleMPlayer` 会出现在「文件」App 的「我的 iPhone」下，也出现在 Finder 里（手机连电脑后选这台设备 → 文件），把歌或整个文件夹拖进去即可。

Documents 就是音乐库本体，导入只是把别处的文件拷进来。

分享有两种到达方式，`FileService.accept` 都处理了：in-place（`LSSupportsOpeningDocumentsInPlace`）给的是原位置 URL，需要拷贝；「拷贝到 App」给的是沙盒 `Documents/Inbox` 里的 URL，直接搬出来——不然库里会多出一个 Inbox 文件夹。App 冷启动时也会兜一次底（`drainInbox`），把上次没搬完的清掉。

支持 MP3 / M4A / M4B / AAC / FLAC / WAV / AIFF / CAF。APE、WMA、OGG 这类 iOS 本身解不了的格式会被当成普通文件显示，不能播放。

## 资源管理器能做什么

根目录就是 Documents，只按目录结构显示，不做任何跨目录聚合：

- **查**：逐层进入文件夹。每行左边是一条窄窄的**类型栏**（带一点底色和一条竖线，把"这是什么"和"它叫什么"分开）：文件夹是文件夹图标，**音频是音符加格式小字**（MP3 / M4A / FLAC…，SF Symbols 没有按格式分的图标，所以格式用文字标出来），图片和文档用各自的图标；正在播放的那一行换成跳动的小柱子，多选时换成勾选圈。
  - 文件夹行：大字号名字 + 「📅 日期 · 📁 子文件夹数 · 📄 文件数」
  - 歌曲行：大字号名字（**按文件本来的名字显示**，不改写、不抽序号）+ 进度条 + 「已听时长 · 文件大小」，右侧是总时长
  - 歌词封面这类非音频文件压成灰色

  `wma`、`ogg`、`ape` 这些 iOS 原生解不了的音频也会被认成音频（音符加格式小字），但仍然灰显、不可播放 —— 图标只负责说明"这是什么"，能放不能放由 `FileService.audioExtensions` 决定。
- **增**：右上角 ＋ 新建文件夹、导入文件或文件夹
- **刷新**：下拉刷新；从别的 App 回到本 App 会自动重扫；＋ 里也有一个「重新扫描」
- **改**：长按任意一行 → 重命名 / 移动到…；点「选择」进多选，底部升起工具栏：全选 / 移动（按钮上带选中数量）/ 重命名（仅单选）/ 删除
- **删**：左滑删除、长按菜单删除、多选删除都是直接执行，不弹确认。完成后单个显示「已删除「xxx」」，多选按类型汇总为「已删除 x 个文件夹，y 个文件」，不再显示物理删除等内部术语。

**播放队列就是当前这一层的音频文件**：点某一首歌，这个目录里的歌（不含子文件夹）就排成了列表；文件夹菜单里的「播放全部」同样只排这一层，子文件夹不参与。

一首歌播放完毕并自动切到下一首时，列表会重新读取当前目录，更新当前曲目和播放进度。

队列中的最后一首播放结束后会停在文件末尾，不会自动跳回 0；再次点击播放会从文件开头重新开始。

App 从后台回到前台时会检查当前歌曲是否仍存在。如果在「文件」App 中删除了它，播放现场会立即清空并退回列表；目录列表也会先清掉旧快照再重扫，避免已删除内容短暂闪现。

播放进度按相对路径记在 `PlaybackProgress` 里：播放中每 3 秒左右记一次，暂停、切后台、退出都会落盘；删文件时连同记录一起清掉。列表里那条细线就是它，播过的部分用强调色。

每条记录里存了**播放当时的时长**（`PlaybackPosition`），不依赖标签里的时长 —— 否则刚导入、标签还没读完的文件，进度条会一直显示 0。正在播放的那一行还会直接用播放器的实时进度，所以它是准的。

**断点续播**：再点开播过的文件会从上次的位置接着播。两个例外交给 `resumeTarget` 判断 —— 只听了 3 秒以内（等于没听）、或者离结束不到 5 秒（接上去等于立刻结束），都从头开始；时长还不知道时不猜，照续。

## 播放器

- 从列表点一首歌会直接**全屏**打开播放界面（`fullScreenCover`，不是 sheet —— sheet 顶部会露出下面一截）。左上角一个向下箭头收起，顶部那条也能下滑关闭。轻点唱片暂停；向左滑动按设置秒数倒退，向右滑动前进；双指单击按设置秒数向前跳转；上滑切到 1.5×，下滑恢复正常速度
- 启动时如果有上次选过的歌曲，会恢复曲目、所属目录的队列和播放进度并打开播放页，无论退出前是在播放还是暂停，但**不会自动出声**；没有可恢复内容时直接显示列表。收起播放页后，如果已有当前歌曲，列表会直接定位到它所在的文件夹
- 播放页中间是一台**带唱臂的红色黑胶唱机**：亮红盘体有密纹沟槽和固定方向的高光，右上角连续弯臂和深色唱头保持固定。黑色盘心显示当前文件夹名称，播放时盘体和标签连续平滑地转（暂停、拖动和变速时会重新对齐）。进度条已播放部分使用红色，背景以黑色和红色氛围光为主
- 顶栏右上角有「接下来播放」队列入口和系统齿轮样式的**播放设置**；倍速也可从进度条上方的调节按钮进入，手势跳转秒数在设置里修改
  - **一键倒计时**：位于进度条上方，按设置里选的预设时间直接开始（默认 30 分钟）；计时中按钮显示剩余量，再点一下取消
  - **倍速调节**：位于进度条上方，点开后显示「减号 / 当前速度 / 加号」调节器
- **倍速** 0.5×–2.0×，步进 0.1，共 16 档；使用加减按钮调节并记住上次选择

  变速时进度条下面会多一行：左边是「按这个速度折算的已用时间」，右边是「按这个速度还要多久」；上面那行始终是文件本身的时间轴。比如 45 分钟的文件在 2.0× 下，第二行的剩余时间会按 2.0 折算。
- **定时停止** 按时间（5/10/20/45 分钟或自定义，壁钟计时）或按曲目（播完 1/2/3/5 首或其他数量）。最后 5 秒淡出，到点暂停并保留进度
- 锁屏与控制中心的控制、耳机线控、后台播放

## 几个实现上的取舍

- **用 AVPlayer 而不是 AVAudioPlayer**：长音频不会整段读进内存。
- **变速用 `engine.rate` 而不是 `play()`**：暂停恢复时要按当前倍速还原，另外 `audioTimePitchAlgorithm` 设成 `.spectral` 才不变调（听书可以把 `AudioPlayer.load` 里改成 `.timeDomain`）。
- **音量交给系统**：App 不设自己的音量条，实际响度由音量键和控制中心决定（iOS 没有 API 能让 App 读写系统音量）。只有定时停止的最后 5 秒会临时改一下 `engine.volume` 做淡出。
- **只存相对路径**：沙盒绝对路径在重装、迁移后会变。
- **标签缓存按「路径 + 大小 + 修改时间」判失效**：所以重命名、移动、替换文件之后封面不会错位。
- **固定深色**：不在浅色模式下提供另一套配色。
