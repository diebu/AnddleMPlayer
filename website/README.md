# AnddleMPlayer Privacy Website

This directory contains the bilingual privacy policy and is the exact artifact
published by `.github/workflows/deploy-privacy-pages.yml`.

After the repository is pushed to GitHub:

1. Open the repository's **Settings → Pages**.
2. Set **Source** to **GitHub Actions**.
3. Run the `Deploy privacy site to GitHub Pages` workflow.
4. Use the resulting privacy URL in App Store Connect:

```text
https://<github-username>.github.io/<repository-name>/privacy.html
```
